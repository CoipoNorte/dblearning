# 🗄️ [dblearning](https://coiponorte.github.io/dblearning/)

Guía interactiva estilo Prisma/Drizzle para aprender bases de datos: SQL, PostgreSQL, MongoDB y ORMs. Sidebar colapsable, demos en vivo y código copiable.

## 🔗 Temas cubiertos

**SQL:** Intro · SELECT · WHERE · INSERT/UPDATE/DELETE · JOINs · Agregación · Subqueries · Índices · Diseño · Tips

**PostgreSQL:** Intro · Setup · Tipos · JSON · Funciones · Transacciones · Views · Seguridad · Performance · Node.js

**MongoDB:** Intro · CRUD · Queries · Schema · Aggregation · Mongoose

**ORMs:** Intro · Prisma · Drizzle · Comparación

## 🛠️ Tecnologías

- **React 18** — Biblioteca de UI
- **Tailwind CSS v4** — Estilos utility-first
- **Vite** — Build tool
- **Lucide React** — Iconos

## 🚀 Ejecutar

```bash
npm install
npm run dev
```
